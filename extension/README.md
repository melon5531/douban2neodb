# 离豆 · 豆瓣 → NeoDB 实时同步（浏览器扩展）

在豆瓣网页上**标记 / 打分 / 写短评**的同时，自动把同样的状态、评分、短评和标签同步到 [NeoDB](https://neodb.social)。页面右下角会弹出同步结果提示。

**v1.1 起内置「历史标记迁移」**：不装 Python、不用导出文件，直接在浏览器里把豆瓣上全部历史标记（看过/想看/在看 + 星级 + 短评 + 标记日期）一键迁移到 NeoDB——扩展现在可以独立完成整个迁移。

## 功能

- ✅ **历史标记迁移**：点插件弹窗里的「开始迁移」，自动分页抓取你在豆瓣的全部书影音标记并同步（增量幂等、可暂停续传、保留原标记日期）
- ✅ 拦截豆瓣「标记 + 打分 + 短评」提交动作，自动同步到 NeoDB
- ✅ 状态映射：看过/读过/玩过 → **完成**；在看/在读/在玩 → **进行中**；想看/想读/想玩 → **愿望清单**
- ✅ 评分映射：豆瓣五星制自动 ×2 换算为 NeoDB 十分制（如 4 星 → 8 分）
- ✅ 短评、豆瓣标签一并同步；豆瓣勾选「仅自己可见」时自动以私密可见性同步
- ✅ NeoDB 未收录的条目会自动触发导入（等待几秒，成功后完成标记）
- ✅ 支持电影 / 电视 / 图书 / 音乐 / 游戏（`movie|book|music.douban.com/subject/...` 与 `www.douban.com/game/...`）
- ✅ 可见范围可选（公开 / 仅关注者 / 仅自己）、可开关自动同步、可关系统通知
- ✅ **数据导出**：一键把 NeoDB 上的全部标记导出为 CSV / Markdown / JSON 本地文件（含状态、类型、评分、短评、标记日期、标签、豆瓣链接）
- ✅ 弹窗显示连接状态与最近同步记录

## 安装（Chrome / Edge / Brave 等 Chromium 浏览器）

1. 下载本仓库，得到 `extension` 文件夹
2. 打开浏览器扩展管理页：
   - Chrome / Brave: 地址栏输入 `chrome://extensions`
   - Edge: 地址栏输入 `edge://extensions`
3. 打开右上角（Edge 在左侧）的 **「开发者模式」** 开关
4. 点击 **「加载已解压的扩展程序」**，选择 `extension` 文件夹
5. 固定到工具栏，点击图标进入设置

> 需要 Chrome 111+（2023 年 3 月起）——插件使用 MV3 的 MAIN world 内容脚本拦截豆瓣请求。Edge/Brave 近两年版本均满足。Firefox 暂不支持。

## 配置 NeoDB 令牌（二选一）

**方式 A · 开发者控制台（推荐，最简单）**

1. 登录 NeoDB，打开 `https://neodb.social/developer/`
2. 在 Dev Console 中点击 **Authorize**，生成 Access Token 并复制
3. 粘贴到插件设置页的「访问令牌」输入框，点击 **保存设置 → 测试连接**

**方式 B · 插件内一键 OAuth**

1. 插件设置页点击 **「一键授权」**，会打开 NeoDB 授权页
2. 登录并同意授权后，页面会显示一串授权码
3. 把授权码粘贴回插件设置页，点击 **「换取令牌」**，令牌自动保存

令牌仅保存在浏览器本地（`chrome.storage.local`），只用于调用 NeoDB API，不会发送到任何第三方。使用自建 NeoDB 实例时，修改「实例地址」并保存，插件会自动申请对应域名的访问权限。

## 使用

**历史标记迁移（v1.1+）**：

1. 在插件设置里配好 NeoDB 访问令牌（下面「配置 NeoDB 令牌」任选一种方式）；
2. 确保浏览器已登录豆瓣；
3. 点扩展图标，在「历史标记迁移」区点 **「开始迁移」**——扩展会自动打开你的豆瓣标记页，
   分页抓取（看过 → 想看 → 在看）并逐条同步到 NeoDB；
4. 进度条实时显示，随时可 **暂停**；再次点击 **继续** 从断点接着跑；
5. 已同步且未变化的条目自动跳过（幂等），重复运行不会产生重复标记；
6. 豆瓣触发风控或登录过期时迁移会自动暂停并提示，稍后点「继续」即可。

> 迁移节奏保守（豆瓣页面间隔约 3 秒、每条之间约 1 秒），上千条标记预计需要 1~2 小时，
> 期间保持豆瓣标签页打开即可。

**日常实时同步**：

配置完成后无需任何操作：像平常一样在豆瓣页面点星级、写短评并保存（或直接点「想看」「看过」），右下角会弹出「已同步到 NeoDB」，可点击直达 NeoDB 条目页。若条目尚未被 NeoDB 收录，会自动导入（可能需等待数秒）；失败时提示可手动搜索。

工具栏弹窗可临时关闭自动同步、查看最近 20 条同步记录；设置页可调整可见性、标签同步等。

**数据导出**：点扩展弹窗的「数据导出」，选 CSV / Markdown / JSON 任一格式，
即可把 NeoDB 上的全部标记（含各状态、评分、短评、标记日期、标签、豆瓣链接）下载为本地文件。
CSV 带 BOM，Excel/WPS 直接打开不乱码；Markdown 适合发布或归档阅读；JSON 便于程序处理。

## 常见问题

- **提示「豆瓣标记未提交成功，已跳过同步」**：豆瓣提交本身失败（多为未登录豆瓣），登录后重试即可
- **提示「令牌无效」**：到 `https://neodb.social/developer/` 重新生成令牌并更新
- **部分条目同步失败**：条目可能无法从豆瓣自动导入，点击提示中的链接手动在 NeoDB 搜索标记
- **长评（影评/书评）暂不同步**：当前版本只同步标记、星级与短评
- **想换可见性**：设置页可选公开 / 仅关注者 / 仅自己，豆瓣勾选「仅自己可见」时始终以私密同步

## 技术说明

- Manifest V3，无任何外部依赖与远程脚本
- `inject/hook.js`（MAIN world）包装页面 XHR/fetch，拦截豆瓣 `/j/.../interest` 提交接口；`content/douban.js`（隔离世界）兜底监听标记表单 submit，两者防抖合并
- `content/migrate.js`（隔离世界）历史迁移器：在同源页面内分页抓取标记列表（DOMParser 解析，带随机间隔防风控），逐条经后台写入 NeoDB；进度存于 `chrome.storage.local`，支持暂停/续传/幂等去重
- `background.js`（Service Worker）调用 NeoDB API：
  - `GET /api/catalog/fetch?url=<豆瓣链接>`：定位条目，未收录自动触发导入（202 轮询、429 退避）
  - `POST /api/me/shelf/item/{uuid}`：写入标记（`shelf_type` / `visibility` / `comment_text` / `rating_grade` / `created_time` / `tags`）
  - `GET /api/me/shelf/item/{uuid}`：迁移时比对已有标记，实现幂等
- 参考：[NeoDB 官方 API 文档](https://neodb.social/developer/)（OpenAPI: `/api/openapi.json`）
